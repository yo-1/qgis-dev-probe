about=For development and verification. This is not a plugin to keep in the QGIS you use for daily GIS work; it belongs in a development profile, brought in when you verify a plugin on a real machine. Verifying a plugin on a real machine is tedious: look at the screen, click through, check the result. It comes back with every pull request, and the GUI part cannot be done headless — a real window has to be there. This plugin lets an MCP client do that verification itself, through a localhost-only server (started manually, off by default). Dev Probe speaks MCP: any AI client that can launch a local stdio MCP server can use it — Claude, Codex, or any other. Verified so far with Claude Desktop, Claude Code, and Codex. It works through a localhost-only server: listing windows and widgets, taking screenshots, running Processing algorithms, and reloading plugins. The execute_code tool is disabled by default and runs only when the user explicitly allows it for the current session. Only QGIS 3.44 is the intended target; other versions are untested. Note: this plugin contains two intentional exec() uses (the session-gated execute_code tool and local recipe loading), which are core to its purpose. Setup and client connection guides are in the GitHub docs (https://github.com/yo-1/qgis-dev-probe/blob/main/docs/CLIENTS.md). / 【開発・検証用】プラグイン開発の実機検証は、画面を見て、操作して、結果を確かめる地味で面倒な作業です。プルリクエストのたびに繰り返され、しかもGUIの確認はヘッドレスではできません。このプラグインは、その検証をAIクライアント(MCP)自身に行わせるための道具です。接続はMCPによるもので、特定の製品に限らず、ローカルのstdio MCPサーバーを起動できるAIクライアントなら使える設計です。実機確認済みはClaude Desktop、Claude Code、Codexです。日常のGIS業務で使うQGISに常駐させる道具ではありません。プラグイン開発の検証をするときに、開発・検証用のQGISに入れて使う道具です。AIは localhost 上のサーバー(手動起動・既定は停止)経由で、ウィンドウや部品の取得、スクリーンショット、Processing の実行、プラグインの再読込ができます。execute_code は既定で無効で、セッションごとにユーザーが明示的に許可した場合だけ動きます。対象は QGIS 3.44 のみで、他バージョンは未検証です。なお、このプラグインには目的上必要な exec() の使用が2箇所あります（セッション許可制の execute_code と、ローカルに置いたレシピファイルの読込）。セットアップとクライアント接続の手順は GitHub のドキュメントにあります（https://github.com/yo-1/qgis-dev-probe/blob/main/docs/CLIENTS.md）。
